## Features
- **Privacy First:** 100% local operation, ~600 KB footprint, zero metrics tracking or telemetry.
- **Freeform Layout (Builder Mode):** Drag, scale, rotate, and snap elements to a magnetic grid without layout restrictions.
- **Backgrounds:** Gradients, static images, and MP4 videos (local or URL) with custom blur, brightness, and playback controls.
- **Search:** Supports Google, Yandex, DuckDuckGo, Bing, voice search, Google Lens, Google AI mode (`udm=50`), and reactive neon borders.
- **Shortcuts & Containers:** Custom bookmarks, top sites auto-import, and grouping icons into customizable containers.
- **Widgets:** Built-in clock, weather, IP address, flag, plus a custom HTML/CSS widget builder.
- **Visual Effects:** 3D Glassmorphism, reactive neon glows, custom CSS editor, and presets.
- **Performance:** Focus mode freezes animations and videos in background tabs; ultra-optimization mode for low-end devices.
- **Backup:** Complete import and export of scene settings via a JSON file.

## Installation
- **Firefox AMO (Recommended):** [Get it on Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/yt-your-tabs/)
- **Manual Installation:** 
  1. Download the source code.
  2. Open `about:debugging#/runtime/this-firefox` in Firefox.
  3. Click **Load Temporary Add-on...**
  4. Select the `manifest.json` file.

## Возможности
- **Приватность:** 100% локальная работа, размер ~600 КБ, полное отсутствие телеметрии и сбора данных.
- **Режим конструктора (Builder Mode):** свободное перемещение, масштабирование, вращение и привязка элементов к магнитной сетке.
- **Фоны:** градиенты, статичные фото и MP4-видео (с локального диска или по URL) с настройкой размытия, яркости и скорости.
- **Поиск:** поддержка Google, Яндекс, DuckDuckGo, Bing, голосового ввода, Google Lens, режима Google AI (`udm=50`) и неоновой обводки.
- **Ярлыки и контейнеры:** добавление закладок, автоимпорт часто посещаемых сайтов и группировка ссылок в настраиваемые блоки.
- **Виджеты:** встроенные часы, погода, IP-адрес, флаг, а также конструктор собственных виджетов на HTML/CSS.
- **Эффекты и стиль:** 3D-стекло (Glassmorphism), неоновое свечение, встроенный CSS-редактор и готовые пресеты.
- **Оптимизация:** режим фокусировки (заморозка анимаций при неактивной вкладке) и ультра-оптимизация для слабых ПК.
- **Бэкап:** полный экспорт и импорт конфигурации через JSON-файл.

## Установка
- **Firefox AMO (Рекомендуется):** [Установить из Mozilla Add-ons](https://addons.mozilla.org/ru/firefox/addon/yt-your-tabs/)
- **Ручная установка:** 
  1. Скачайте исходный код.
  2. Откройте `about:debugging#/runtime/this-firefox` в Firefox.
  3. Нажмите **Загрузить временное дополнение...**
  4. Выберите файл `manifest.json`.
