Динамическая неоновая обводка при наборе

При наборе текста по периметру поиска переливается плавная неоновая обводка без заливки фона самого инпута.

«Всегда» держит обводку включённой постоянно — удобно, если хотите оставить только эту неоновую анимацию вокруг поиска.

Отключено по умолчанию. При выключении фон поиска остаётся чистым, анимируется только внешняя неоновая обводка.

Если выключить, обводка станет статичным градиентом без перетекания цветов.

Если выключить, пропадёт размытое свечение (glow) вокруг строки, обводка останется чёткой.
